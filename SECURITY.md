# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.x | Yes |
| < 1.0 | No |

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub private vulnerability reporting: open the
repository's **Security** tab, choose **Report a vulnerability**, and describe the issue, affected versions and
steps to reproduce.

We aim to acknowledge reports within a few days and to keep you informed while we investigate and prepare a fix.
This is a best-effort open source project, so we cannot promise specific timelines. Fixes are released as
patch versions of the supported line, and reporters are credited if they wish.
